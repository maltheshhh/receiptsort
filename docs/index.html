Reads

Drop in photos, scans or PDFs. A local vision model pulls out vendor, date, invoice number, currency, subtotal, tax, total and category.

Files

Each receipt is copied to a month and category folder with a name you can search: date, vendor, amount. Your originals stay where they are.

Flags

Missing fields, totals that don't add up and repeated receipts go to a review folder. The tool says when it isn't sure instead of guessing.

sorted/ ledger.csv 2026-09/ Software/ 2026-09-03_Figma_12.00.png Travel/ ... _needs_review/ 2026-09-10_Uber_400.00.png

A folder your accountant can open.

The ledger has one row per receipt, with the path to the filed copy. Run it every week on the same inbox: files already in the ledger are skipped by checksum, so nothing is read or filed twice.

Why it runs on your machine

Client data stays put

Invoices carry client names, rates and bank details. Many freelancers are under NDAs. Nothing is uploaded, and it works with the network off.

No fee per page

Hosted vision APIs bill by the page. Local inference costs nothing per receipt, so a busy month costs the same as a quiet one.

Swap the model

Any Ollama vision model works. Try a newer one the week it ships, or fine-tune for your own bills and edit the category list to match your books.

Three commands

Install Ollama, pull a vision model, point the script at a folder. PDF receipts need one extra package. The default model is qwen2.5vl:7b.

# 1. open vision model ollama pull qwen2.5vl:7b # 2. optional, for PDFs pip install pymupdf # 3. sort a folder python3 receiptsort.py ~/Downloads/receipts --out ~/receipts-sorted
